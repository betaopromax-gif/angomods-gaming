🎯 Gerador de sensibilidade

📱 OPTIMIZAÇÃO ANDROID

🧹 Limpeza

  • Limpa o cache de aplicações pesadas.
  • Apaga ficheiros desnecessários.
  • Evita aplicações a funcionar em segundo plano.
  • Deixa espaço livre na memória interna.

⚡ Desempenho

  • Fecha aplicações antes de jogar.
  • Desativa gravação de ecrã se não estiveres a usar.
  • Evita jogar enquanto carregas.
  • Reduz gráficos se o telefone aquecer.

🌡️ Temperatura

  • Evita sol direto.
  • Faz pausas quando o telefone aquece.
  • Evita aplicações de arrefecimento falsas.
  • Não bloqueies a ventilação do aparelho.

🎮 Free Fire

  • Testa gráficos baixos.
  • Desliga efeitos que não precisas.
  • Testa uma sensibilidade de cada vez.
  • Reinicia o jogo se começar a ficar lento.

🧪 SHIZUKU LAB

Combinações de ferramentas Android com Shizuku.

🛠️ Shizuku + Canta

Combinação para gerir aplicações que suportam operações avançadas de gestão de apps.

Confirma as permissões antes de desativar ou remover aplicações.

📂 Shizuku + FV File Explorer

Exploração e gestão de ficheiros e pastas em locais suportados, conforme as permissões disponíveis.

⚙️ Shizuku + App Ops

Gestão e análise de permissões de aplicações através de ferramentas compatíveis.

📊 Shizuku + ferramentas de diagnóstico

Usa ferramentas de diagnóstico para analisar o comportamento do sistema. Shizuku não aumenta FPS automaticamente.

Como iniciar o Shizuku

  1. Instala Shizuku da fonte oficial.
  2. Abre as instruções de arranque para o teu Android.
  3. Segue o método de depuração sem fios, se suportado.
  4. Confirma o estado de execução no Shizuku.
  5. Autoriza apenas aplicações que conheces.

O método de arranque varia conforme a versão Android. Não concedas permissões indiscriminadamente.

Site oficial do Shizuku

⚠️ Não faças isto

  • Não desactives serviços críticos do Android.
  • Não executes scripts aleatórios de FPS.
  • Não concedas acesso a apps desconhecidas.
  • Não alteres valores do sistema sem saber como restaurá-los.
